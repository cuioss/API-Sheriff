# Small per-arm samples supported a fix hypothesis for an intermittent failure that a large sample refuted

Source: kidicap-gateway-requirements PLAN-32 (PR #466), D1/D2 diagnosis of the Http2EarlyResponseResetIT timeout (#455).

## What happened

Small diagnostic samples seemed to support the first fix hypothesis, a `SO_LINGER 0` / socket-linger setting. A 120-run-per-arm comparison refuted it (5/120 vs 3/120). The plan had already been outlined around that hypothesis, and unwinding it cost two re-outlines and several stale-assessment Q-Gate rounds.

## Rule

For intermittent failures at low single-digit percent rates, fix a minimum sample size per arm before any arm's result may change the outline. Choose it so that the expected failure count in the control arm is clearly above zero (100+ runs at about 1-5 %). Record arm results as "n runs, k failures", never as "fixed" or "not fixed".
