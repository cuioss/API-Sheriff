## Vision

Everything API Sheriff should become **after** its first release cut, in three strands:

1. **Threat hardening (WS-05)** — turn the gateway from one that *rejects* bad requests into one
   that *recognises campaigns*: close the endpoint-existence oracle, build a per-client detection
   substrate, score cross-request anomalies into a loud SIEM-ready signal, and add an in-process
   deception layer.
2. **Management-plane introspection (WS-06)** — expose the route inventory the gateway already
   compiles at boot, authenticated and read-only, in the formats WAFs and API-security tools ingest.
   It is the *authorized* form of the enumeration map WS-05 hides from attackers.
3. **The integration sample (WS-03)** — a deliberately simple SPA that proves the BFF end to end
   against a real IdP and ships as the reference a downstream frontend team copies.

**"Done" is not defined yet.** This epic was created by moving seven specs across; it has not been
decomposed against a re-grounded tree. Decomposition is the first real act — see START HERE.
