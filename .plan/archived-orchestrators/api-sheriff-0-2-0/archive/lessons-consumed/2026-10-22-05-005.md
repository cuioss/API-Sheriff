# A callback that can run on the upstream event loop never writes RoutingContext data

A callback that can run on another event loop than the request's (timers armed on the upstream side, late completions of the upstream leg) never writes `RoutingContext` data, which belongs to the client event loop. It writes only to thread-safe structures shared by both sides. Reviews of edge code ask, for every callback, which loop it runs on.
