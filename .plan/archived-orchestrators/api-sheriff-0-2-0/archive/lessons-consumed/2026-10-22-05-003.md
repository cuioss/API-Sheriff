# An ADR amendment that fixes a status per timing case gets one test per timing window

When a plan writes an ADR amendment that fixes the response status per timing case, it adds one test per timing window the amendment names (before hand-over to the upstream; after hand-over with the response head unwritten; after the head is written), so the code cannot diverge from the amendment unnoticed.

PLAN-V02-45: ADR-0060 A2 says the upstream status stands once it was sent, but the code answered 502 when the request-body deadline expired after hand-over and before the head was written. Code review found it; no test covered that window.
