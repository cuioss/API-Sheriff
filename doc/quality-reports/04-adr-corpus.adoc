== Contract-Test Constraints on `doc/adr/`

1. *`AdrOrdinalUniquenessContractTest`*: Every file in `doc/adr/` must begin with a unique 4-digit prefix `^\d{4}-`.
2. *`AdrRecordLengthContractTest`*: Every file in `doc/adr/` must have a `== Status` heading, at least one subsequent `== ` heading, and at most `500` body lines.
3. *Inbound Deep-Link Anchors (`[[...]]`)*: Architecture, user, development, and sibling ADR documents deep-link to specific section anchors inside `doc/adr/*.adoc` (for example, `0027#_live_key_set_readiness`, `0058#_cookie_envelope_wire_format`, `0060#_why_not_in_memory_sliding_window_rate_limiting`, `0069#_accepted_costs`, `0073#_why_four_separate_executors`). Every existing `[[_...]]` anchor inside `doc/adr/*.adoc` *must* be preserved when slimming.
