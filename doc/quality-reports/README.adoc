== Review Criteria

. *Correctness*: the docs agree with the code and with each other.
. *Structure*: no monolithic file. Heading depth stays at `===` or above, with deeper levels only where nesting is genuine.
. *Diagrams*: embed the existing SVGs in `doc/resources/diagrams/` (31 files) before drawing new ones.
. *Voice*: follow `pm-documents:ref-narrative-styles`. That is reference-spec for `doc/configuration*` and `doc/LogMessages.adoc`, tutorial-walkthrough for `doc/user/`, and engineering-narrative for architecture, development and ADRs.
. *Size*: replace repetition with tables, cross-links and diagrams.
. *History*: remove pre-1.0 migration notes, dated lab notebooks, PR disposition logs and leaked tooling or prompt text from current-state prose.
